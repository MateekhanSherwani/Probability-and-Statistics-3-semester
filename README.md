# Probability & Statistics Project

## Impact of Online Education on Students

## Project Overview

This project was developed as part of the **Probability and Statistics** course. It analyzes the **impact of online education on students** using statistical methods and secondary data analysis.

The objective of this project is to examine how different factors such as internet quality, study hours, and attendance influence students' academic performance and overall satisfaction with online learning.

## Dataset

The dataset consists of **20 student observations**, where each record represents one student's academic performance and learning experience.

### Variables Included

- Student ID
- Gender
- Age
- Internet Quality
- Study Hours per Day
- Attendance Percentage
- Midterm Score
- Final Score
- GPA
- Satisfaction Level

## Project Objectives

- Analyze the impact of online education on student performance.
- Compare academic outcomes based on different learning conditions.
- Identify relationships between study habits, internet quality, attendance, and GPA.
- Evaluate students' satisfaction with online learning.

## Statistical Analysis

The project applies fundamental statistical techniques, including:

- Data Collection
- Data Organization
- Descriptive Statistics
- Frequency Distribution
- Mean, Median & Mode
- Data Visualization
- Comparative Analysis
- Interpretation of Results
